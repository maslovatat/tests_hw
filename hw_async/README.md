# Async Homework Tracker API

Работа демонстрирует асинхронное взаимодействие микросервисов через брокер сообщений RabbitMQ на примере трекера домашних заданий (из прошлой домашки). 
В прошлой работе был спроектирован синхронный REST API, который принимал задания и сразу возвращал ответ. Теперь разделенная на два микросервиса система и брокер сообщений **RabbitMQ** , который мгновенно отвечает пользователю `202 Accepted`, должны проанализировать поставленную пользователем задачу (например, сгенерировать текст напоминания и посчитать, сколько дней осталось). Теперь API (Сервис А) мгновенно отвечает пользователю `202 Accepted` («Задача принята»), а фоновый обработчик (Сервис Б) неспешно анализирует дедлайн и присылает готовый статус обратно.
