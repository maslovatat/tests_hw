# Homework Tracker API

API позволяет студенту вести трекер домашних заданий (создавать дедлайны, просматривать список, отмечать выполненные задачи и удалять их). Например, добавить задачу «Сдать ДЗ 8 по разработке приложений до субботы».

## Что там вообще есть:

1. Файл `api.yaml` написан в формате OpenAPI 3.0. Содержит 5 эндпоинтов (GET список, GET один, POST, PATCH, DELETE) и DTO-схемы в `components`. Спека валидна и проверена в `editor.swagger.io`. Ошибочные коды (401, 403, 404) прописаны с пояснениями.
2. Папка `service` содержит сгенерированный каркас сервера на Python (Flask).

## Как делали

1. Спецификация `api.yaml` была спроектирована с помощью AI-агента **Claude**. Логика работы с сущностями (заданиями) была продумана самостоятельно, а агент выступил в роли генератора YAML-кода:
   * **Промпт агенту:** «Напиши OpenAPI 3.0 спецификацию для Homework Tracker API. Нужны 5 эндпоинтов с разными глаголами:
     1. `GET /tasks` — получить список всех заданий (ошибка 401, если не авторизован).
     2. `POST /tasks` — создать новое задание с дедлайном (ошибка 400, если не указан дедлайн).
     3. `GET /tasks/{id}` — получить одно задание по ID (ошибка 404, если не найдено).
     4. `PATCH /tasks/{id}` — обновить статус задания, например, отметить выполненным (ошибки 403, если нельзя менять чужое, и 404).
     5. `DELETE /tasks/{id}` — удалить задание (ошибки 403 и 404).
     Вынеси DTO-схемы (Task, NewTask, UpdateTask) в блок components».
   * После генерации спека была проверена и доработана вручную в `editor.swagger.io` на предмет валидности синтаксиса и соответствия требованиям задания.

2. Каркас сервиса сгенерирован встроенным инструментом Swagger Editor (Generate Server -> python-flask) и сохранен в папку `service`. 

## Запуск (для python-flask)
